# 影刀「执行Python代码」指令专用片段
#
# 这些文件有两个身份：
#   1. 整段粘进影刀的「执行Python代码」指令里，直接跑
#   2. 用命令行单独跑（`python 02_parse_clipboard.py --text "..." --out x.ini`），
#      方便不打开影刀也能先验证逻辑 —— tools/test_rpa.py 就是走这条路做自动测试的
#
# 影刀的变量绑定规则（实测/官方文档）：
#   * 「输入变量」填 {"clip_text": ${剪贴板文本}}  → Python 里就是一个名为 clip_text 的变量
#   * 「输出变量」填 ${结果}                      → Python 里同名变量会回传给影刀，支持 字符串/数字/列表/字典
#   * 变量没注入时脚本不会炸（内部用 globals().get 兜底），但输出会是空的
#
# 共同约定：只依赖 Python 标准库。影刀自带的 Python 环境不保证有 numpy/pandas。
